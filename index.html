Smart Mirror in Python

Smart Mirror Interface: A Python-based smart mirror application built as a group project, combining weather, calendar, and news feeds with Spotify playback control. Includes webcam-based touchless interaction: a MediaPipe hand-tracking module detects a pinch gesture (thumb + index finger) via OpenCV to let users "click" UI elements without touching the mirror.
